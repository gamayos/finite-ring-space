Paradoxes of Infinity as Reductio ad Absurdum

Russell’s antinomy, Gödel’s incompleteness, and Turing’s undecidability are usually read as limitations to be endured within an infinitary foundation. We propose a different diagnosis: each classical paradox combines constitutive baseline principles—consistency and effective determinacy—with one completed-infinity premise: absolute totalities (AT), an internalized registry (IR: the object theory interprets Robinson’s $Q$), or unrestricted Choice (AC$\infty$). Turing’s undecidability separates as an external non-existence theorem.
