Reading the package column

checks
The number of the paper's predicates the validation package checks — green when every check passes, red when one fails; opens the notebook on Google Colab, one cell per predicate. The title of such a paper opens its predicate ledger.
proofs
The number of predicates proved in Lean; opens the paper's core module (no Mathlib, no axioms) as one executable file in the Lean web editor. Two counts where the paper has both libraries: green the predicates proved in the core (no axioms), teal those proved on Mathlib (classical), each opening its module's executable file; the two may overlap.
ledger
The paper's predicate ledger: every claim tagged, sourced and, where it admits a finite check, witnessed by a script.
notebook
The validation notebook, opened directly on Google Colab: the paper's scripts run in the browser, the ledger predicates they witness named.
lab
An interactive rendering of the paper's construction.
